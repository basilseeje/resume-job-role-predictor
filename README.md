# Resume Job Role Prediction using Deep Learning
## Description
This project predicts job roles based on skills using a deep learning model integrated with a Flask web application.

## Technologies Used
- Python
- TensorFlow
- Flask
- Scikit-learn
- HTML/CSS

## Features
- Input skills manually
- Predict job role
- User-friendly web interface

## How to Run
1. Clone the repository
2. Install dependencies (pip install -r requirements.txt)
3. Run app.py
4. Open http://127.0.0.1:5000

## Output
Displays predicted job role based on user skills
